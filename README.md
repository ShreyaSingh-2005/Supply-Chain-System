# Supply Chain Route Optimization System 

A C++ project that simulates a real-world supply chain and logistics network using various Data Structures and Algorithms.  
The system allows users to manage routes between suppliers, warehouses, hubs, and delivery centers while also analyzing connectivity, delivery costs, and dependencies.

This project was built to demonstrate how multiple DSA concepts can work together in a practical real-world application.

---

## Features

- Add and manage supply chain nodes
- Create transportation routes with associated costs
- Resolve dependencies between nodes using Topological Sort
- Find the shortest/optimal route using Dijkstra Algorithm
- Analyze network connectivity using DSU
- Simulate route failures in the network
- Perform shipment cost analysis using Prefix Sum
- Find maximum shipment cost over consecutive days using Sliding Window

---

## DSA Concepts Used

- Graphs
- Dijkstra Algorithm
- Topological Sort
- Disjoint Set Union (DSU)
- Binary Search
- Breadth First Search (BFS)
- Prefix Sum
- Sliding Window Technique
